# Photo Album — Personal Offline Vault

English UI. Photos, videos, music, PDFs on phone/SD card with category folders, players, and unique vault tools.

## Core
- Custom album location (SD / phone)
- Categories, copy / cut / paste, conflict dialog (Skip / Replace / Keep both)
- Gallery share → category picker + Copy/Cut (system Gallery delete confirm)
- WhatsApp share out
- **Inbox** auto destination for shares (Vault settings)

## Media
- Music player: play/pause, seek, ±10s, shuffle, repeat, speed, sleep timer, mini player, notification
- **Play folder** / **Play all nested music**
- **Crossfade** between tracks (Vault settings)
- Video fullscreen player
- Auto search: Music / Video / Photos / Docs + OCR text matches
